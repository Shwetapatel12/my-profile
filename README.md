# Shweta Patel - Portfolio (React + Vite)

## Run on your computer
```
npm install
npm run dev
```
Open the address shown (usually http://localhost:5173).

## What is in this version
- Split into React components (`src/components/`) with a hooks file
- Remembers the visitor's colour theme and dark/light choice
- Mobile menu (☰), photo tilt, "Read more" on long projects, contact form that opens the visitor's email app

## Edit
- `src/data.js` - your links, skills, experience and projects. **Put your LinkedIn and GitHub URLs here** (replace YOUR-USERNAME).
- `src/App.jsx` and `src/components/*` - page sections (React)
- `src/styles.css`, `src/enhance.css` - colours, fonts, animations (CSS)
- `index.html` - page title and fonts (HTML)
- `src/assets/profile.jpg` - your photo, `public/shweta_patel_cv.pdf` - your CV

## Deploy on GitHub Pages
1. Create a repository on GitHub and upload ALL files of this folder (not the zip).
2. Settings > Pages > Source: **GitHub Actions**.
3. Push to the `main` branch. The included workflow builds and publishes the site.
4. Your site opens at https://yourusername.github.io/reponame/
